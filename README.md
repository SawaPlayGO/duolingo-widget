## Файлы релиза

- `.msixbundle` — основной пакет для установки приложения.
- `-x64.exe` — исполняемый файл приложения, не самостоятельный установщик; для работы плитки сначала установите bundle.
- `.cer` — публичный сертификат подписи. Если секреты сертификата в GitHub не заданы, workflow создаёт временный самоподписанный сертификат и публикует его `.cer`. Перед установкой bundle добавьте этот сертификат в хранилище Windows «Доверенные лица». Приватный `.pfx` в релиз не попадает.
